# Boosty Loader

Удобный интерфейс на Tauri для открытого CLI-проекта
[boosty-downloader](https://github.com/Glitchy-Sheep/boosty-downloader).

Приложение позволяет:

- сохранить Authorization и Cookie локально;
- получить credentials через встроенный helper-скрипт;
- скачать все посты автора или один пост по ссылке;
- выбрать посты, видео Boosty, внешние видео, файлы и аудио;
- выбрать качество видео и задержку между запросами;
- видеть журнал работы, остановить процесс и продолжить синхронизацию позже.

## Запуск для разработки

Понадобятся Rust, Bun и Python 3.10+.

```bash
bun install
bun run tauri dev
```

При первом запуске нажмите «Установить» в верхней части окна. Приложение создаст
изолированное Python-окружение в своём каталоге данных и установит туда
`boosty-downloader` вместе с актуальным набором корневых сертификатов `certifi`.
Этот набор явно используется для HTTPS-запросов из managed-окружения, поэтому
приложение не зависит от состояния сертификатов системного Python. Системные
Python-пакеты не изменяются.

## Сборка

```bash
bun run tauri build
```

## Данные и безопасность

Настройки и `config.yaml` хранятся в стандартном каталоге данных приложения.
На Unix-платформах файлам с credentials назначаются права `0600`. Значения
передаются только локально запущенному `boosty-downloader`; приложение не имеет
собственного сервера.

Скачивайте только материалы, к которым у вас есть законный доступ. Сам
`boosty-downloader` распространяется по лицензии MIT.
